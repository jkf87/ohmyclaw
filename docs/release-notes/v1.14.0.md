## 1. sqlite 세션 스토어 — 긴 작업 재개

긴 작업이 중단되면 **처음부터 다시 해야 했습니다.** 체크포인트가 레포에 하나도 없었고, 재시도 정책은 `max: 1` 에 처음부터 재시작이라 작업이 길수록 완주 확률이 떨어지는 구조였습니다.

`skills/ohmyclaw/session-store.sh` 를 추가했습니다.

| 테이블 | 역할 |
|---|---|
| `sessions` | 수명주기 + 하트비트 + 재개 횟수 |
| `checkpoints` | 단계별 산출물 (seq 단조증가) |
| `tasks` | 태스크 원장 — 재개 입도를 결정 |

```bash
$ session-store.sh resume s1
{"session_id":"s1","last_stage":"work","tasks_done":1,
 "tasks_pending":2,"remaining_task_ids":"t2,t3"}
```

핵심 두 가지입니다.

1. **`done` 태스크는 재실행하지 않습니다.** 재개의 존재 이유입니다.
2. **고아 회수** — `running` 상태로 죽은 태스크는 `pending` 으로 되돌립니다.

WAL + busy_timeout 으로 sqlite 가 직렬화하므로 파일락이 없습니다. 8 워커 동시 쓰기 80/80, seq 충돌 0 으로 검증했습니다.

> v1.12.0 의 result-aware deduper 와는 **다른 층**입니다. deduper 는 같은 툴콜 반복(폭주)을 억제하고, 이건 중단된 작업의 재개를 다룹니다.

## 2. 버전 체크 버그 수정

v1.13.1 의 `_check_update` 가 **문자열 비교**를 하고 있었습니다.

```bash
[[ "$cached_latest" != "$local_v" ]]   # 버그
```

두 가지가 틀립니다.

1. **로컬이 최신 릴리스보다 앞서면** — 즉 개발 중일 때 — "업데이트 있음"을 영원히 출력합니다. 메인테이너가 가장 자주 겪는 케이스입니다.
2. `1.9.0` vs `1.11.0` 같은 자리수 차이를 오판합니다.

`_semver_gt` 로 숫자 필드별 비교하도록 고쳤습니다. 프리릴리스 꼬리표는 제거 후 비교하고, 숫자가 아닌 값이 오면 알리지 않습니다.

## 3. 별(star) 안내

작업이 **성공했을 때만**, 대화형 터미널에서만 저장소 링크를 안내합니다.

- **링크만 안내합니다.** 토큰을 읽거나 API 로 대신 누르는 동작은 하지 않습니다.
- **TTY 에서만** — 파이프·리다이렉트·CI 에서는 출력하지 않습니다. 기계가 읽는 출력에 홍보 문구를 끼워넣으면 파싱이 깨집니다.
- **30일 쿨다운**, `ohmyclaw star --never` 로 영구 해제, `--force` 로 다시 보기.
- 실패한 작업(rc≠0) 뒤에는 발화하지 않습니다.

## 5. GPT-5.6 메타데이터 정정

v1.11.0 의 GPT-5.6 항목이 관측 근거 없는 성능 서열을 담고 있었습니다. 설치본 카탈로그를 직접 읽어 정정했습니다.

**Sol / Terra / Luna 는 컨텍스트(1.05M)·출력(128k)·reasoning·이미지 입력이 전부 동일합니다.** 다른 건 비용과 기본 effort 뿐입니다.

| 모델 | 비용 in/out (1M) | 기본 effort | ultra |
|---|---|---|---|
| Sol | $5 / $30 | low | ✅ |
| Terra | $2.5 / $15 | medium | ✅ |
| Luna | $1 / $6 | medium | codex 제외 |

- Sol 의 `reasoningEffort: "ultra"` → 실측 기본값은 `low` 입니다.
- Terra 를 "최난도 전용"으로 두고 reasoning HIGH 에서 Sol 보다 우선시키던 것을 되돌립니다. Terra 는 Sol 의 상위가 아니라 **절반 가격의 동급**이라, 선택은 성능이 아니라 비용 결정입니다.
- Luna 의 "추론 깊이는 얕음" 서술을 제거했습니다. 실측상 유일한 제약은 codex 런타임의 ultra 미지원입니다.
- `security` 오버레이가 MEDIUM 에 Sol, HIGH 에 Terra 를 주던 **역전**을 바로잡았습니다.
- 운영 관측치인 `loopRisk` / `loopGuard` 는 반박 근거가 없어 그대로 보존했습니다.
